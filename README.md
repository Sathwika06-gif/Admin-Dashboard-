# Admin Analytics Dashboard (MEAN Stack)

## 📌 Project Overview

This project is a full-stack **Admin Dashboard with Analytics & Reporting** built using the **MEAN stack (MongoDB, Express.js, Angular, Node.js)**.

It allows administrators to monitor key metrics, manage users, and visualize data through interactive charts.

---

##  Features

*  Dashboard with analytics (users, sales, metrics)
*  Real-time charts using Chart.js
*  User management (CRUD operations)
*  Authentication & Authorization (JWT-based)
* Role-based access control (Admin/User)
*  Fully responsive UI

---

##  Project Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Sathwika06-gif/Admin-Analytics-Dashboard.git
cd Admin-Analytics-Dashboard
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

Run backend:

```bash
npm start
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
ng serve
```

Frontend will run at:

```
http://localhost:4200
```
